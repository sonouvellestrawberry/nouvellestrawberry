# 환승로그

연애 리얼리티에 나간 출연자의 아이폰을 직접 들여다보는 인터랙티브 시뮬레이션.

지금은 **1일차**까지 플레이할 수 있어. 스토리 설정은 [STORY.md](STORY.md)에 있어.

## 실행

- 파일을 받아서 `index.html`을 브라우저로 열면 돼.
- GitHub Pages로 열려면: 레포 **Settings → Pages → Branch: `main`, 폴더: `/ (root)`** 로 저장. 1~2분 뒤에 `https://<아이디>.github.io/<레포>/` 에서 열려.

## 파일 구성

| 파일 | 내용 | 직접 고칠 일 |
|---|---|---|
| `config.js` | 이름, 인스타 아이디, 사진, 아이콘, 단체사진 클릭 위치 | 많음 |
| `story.js` | 대화, 선택지, 단서, 편지, 프로필 | 많음 |
| `app.js` | 엔진, 앱 화면 | 거의 없음 |
| `insta.js` | 인스타 게시물, 댓글 | 가끔 |
| `tw.js` | 하루가 끝난 뒤 시청자 반응 (트위터) | 가끔 |
| `ui.js` | 터치, 제스처 | 없음 |
| `style.css` | 디자인 | 가끔 |
| `assets/` | 사진, 아이콘 넣는 폴더 | 사진 넣을 때 |

## 이름 바꾸기

`config.js`의 `CAST`에서 `n`(풀네임), `s`(짧은 이름)를 바꾸면 돼. 이/가, 은/는 같은 조사는 받침에 맞춰 자동으로 바뀌어.

스토리에서 이름을 쓸 때는 이렇게 써.
- `{ex}` 풀네임, `{ex.s}` 짧은 이름
- `{ex.s|이가}` 짧은 이름 + 이/가 (조사 종류: `이가` `은는` `을를` `과` `아야` `이` `으로` `이랑`)

## 사진, 아이콘 넣기

1. `assets/` 폴더에 이미지를 올려.
2. `config.js`의 `ASSETS`에 경로를 적어.

```js
avatars:{ me:'assets/me.jpg', ex:'assets/ex.jpg' },
photos:{ group:'assets/group.jpg', us1:'assets/us1.jpg' },
icons:{ talk:'assets/talk.png' }
```

비워두면 기본 그림이 나와. 단체사진을 바꾸면 `GROUP_SPOTS`의 x, y(%)를 사진 속 얼굴 위치에 맞춰줘.

사진 키 목록: `group` 단체사진, `us1`~`us9` 우리 앨범, `r1`~`r12` 최근 항목, `shot1` 스토리 캡처, `sleep` 삭제된 사진, `meNow` 내 프사, `exNow`·`exOld` 태오 프사, `cover` 플레이리스트 커버, `ig1`~`ig6` 공개 계정 게시물

## 저장

플레이어 이름과 4자리 비밀번호로 **그 브라우저에** 저장돼. 다른 기기에서는 이어할 수 없어.

## 조작

- 잠금화면: 아래에서 위로 쓸어올리기
- 홈으로: 화면 맨 아래 막대를 위로 쓸어올리기 (또는 탭)
- 뒤로: 왼쪽 가장자리에서 오른쪽으로 밀기
- 메시지 공감: 말풍선 길게 누르기 (컴퓨터에선 우클릭이나 더블클릭)
- 힌트: 맨 위 검은 섬 누르기. 30초 넘게 아무것도 안 하면 저절로 떠
